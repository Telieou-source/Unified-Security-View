Empty dependency array memoises runSimulationTick for the component's lifetime. The stable reference allows useEffect to include it in its dep array without triggering unnecessary interval re-wires on every render.
sanitizedRef — stale-closure escape hatch · lines 36–37
The callback closes over sanitizedRef at mount, but sanitizedRef.current is updated on every render (line 37). Reading .current inside the callback gives the latest buffer without adding sanitizedEvents to useCallback deps — which would regenerate the function and restart the clock on every tick.
