Factor Weight Condition
Shared user identity 0.40 newEvent.userId present in ≥1 match
Matching event type 0.30 newEvent.type present in ≥1 match
Destination subnet overlap 0.20 dstIp /16 prefix differs (cross-domain target)
Temporal proximity bonus 0.10 linear decay over the 10 000 ms window
* Final score is capped at 1.0 to remain a valid probability. */

130 matches: SanitizedEvent[],
131 windowMs: number = 10_000

135 // ① Shared user identity — weight 0.40
136 const sharedUser = matches.some((e) => e.userId === newEvent.userId);
137 if (sharedUser) score += 0.40;
138
② EVENT TYPE matching event type+0.30
139 // ② Matching event type — weight 0.30
140 const typeMatch = matches.some((e) => e.type === newEvent.type);
141 if (typeMatch) score += 0.30;
142
③ SUBNET destination subnet overlap — /16 prefix differs across domains+0.20
143 // ③ Destination subnet overlap — weight 0.20
144 // Subnets differ by design (cross-domain), but converge on the same /16 gateway class
145 const newSubnet = newEvent.dstIp.split(".").slice(0, 2).join(".");
146 const subnetMatch = matches.some((e) => {
147 const mSubnet = e.dstIp.split(".").slice(0, 2).join(".");
148 return mSubnet !== newSubnet; // cross-domain, same target address class
149 });
150 if (subnetMatch) score += 0.20;
151
④ TEMPORAL proximity bonus — linear decay toward window edgeup to +0.10
152 // ④ Temporal proximity bonus — up to 0.10 (linear decay toward window edge)
153 const now = Date.now();
154 const minDeltaMs = Math.min(...matches.map((e) => Math.abs(now - e.timestamp)));
155 const temporalBonus = Math.max(0, 0.10 * (1 - minDeltaMs / windowMs));
156 score += temporalBonus;
157
⑤ CAP clamp final score to [0.0, 1.0] — valid probability range
158 return Math.min(1.0, score); // cap at 1.0
