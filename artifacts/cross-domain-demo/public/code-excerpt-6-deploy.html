ℹ
No server required to serve dist/  —  The Demo SIEM application is a fully static single-page application (SPA). All cross-domain simulation logic (simulation.ts), correlation engine (CorrelatedView.tsx), and CrossDomainGuard sanitisation pipeline run entirely in the browser via React 18 state and Web Crypto API. The built dist/ folder contains only index.html + a JS chunk + a CSS chunk — deployable to any static host (Netlify, Vercel, GitHub Pages, S3, etc.) with zero server-side configuration.
